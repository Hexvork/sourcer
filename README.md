# 猎头简历搜寻系统（Resume Hunter）

本地运行的简历匹配工具。**HTML 前端 + Node.js + SQLite + Markdown 简历池**，不使用 Python。

## 快速开始

1. 双击 **`start.bat`**（首次会自动 `npm install`，然后启动并打开浏览器）
2. 浏览器访问 `http://127.0.0.1:3000`
3. 把下载的简历（PDF / Word .docx / .doc / TXT）放进 **`简历`** 文件夹

> 旧版 Python 实现已移到 `_旧Python版本备份/`，本系统不再使用。

## 工作流程

1. **放入简历**：文件丢进 `简历/`。
2. **自动归类**：后台实时监测 `简历/`，解析文件内容，把原文件搬入 `简历池/原始文件/<分类>/`，并在 `简历池/<分类>.md` 中生成简洁的 Markdown 简历索引（含姓名、性别、年龄、职业、经历、大学、其他重要信息、绝对路径）。
3. **搜索匹配**：在「简历搜寻」页输入岗位需求（可多个），AI 逐份阅读 Markdown 简历池并打分，只展示 **≥ 70%** 的简历卡片。
4. **打开原件**：单击卡片，系统会用默认程序（WPS 若为默认 Word/PDF 阅读器则自动使用 WPS）打开该简历文件。

## 功能说明

### 匹配度颜色
- 70% ~ 80%：黄色
- 80% ~ 90%：蓝色
- 90% ~ 100%：绿色

### 匹配度圆环
- 外圈：按分数走完的进度环，颜色随区间变化。
- 内圈：实心圆随匹配度升高而变大（70% 最小、100% 最大）。
- 圆环中央显示数字。

### 简历卡片
每张卡片包含：姓名、性别、年龄、职业、大学、文件地址，下方小字说明匹配理由；单击卡片打开原文件。一行展示 4 个。

### 简历匹配度（Header 右侧）
拖入两份简历文件，AI 给出两份简历的匹配度分数、共同点与差异点。

### 历史（Header 右上角）
记录所有对话（搜索与 A↔B 对比），并保存 AI 当时找到的简历，可一键重新打开。

### 模型配置（左侧设置页）
- 可添加多个 API（OpenAI 兼容），每个 API 填：名称、Base URL、API Key。
- 一个 API Key 可配置多个模型；每个模型可勾选「多模态」（圆形勾选框）。
- API 卡片可拖动排序；调用时按优先级依次尝试，失败自动切换下一个。
- 模型调用失败时自动降级为关键词粗筛，系统仍可使用。

## 目录结构

```
简历/                     放原始简历（实时监测）
简历池/                   分类后的 Markdown 简历池
  原始文件/<分类>/         搬入的原简历文件
data/resume.db            SQLite 数据库
public/                   前端 HTML/CSS/JS
lib/                      后端逻辑（解析/LLM/分类/数据库）
server.js                 后端入口（Express + chokidar + node:sqlite）
```

## 注意事项

- 需要 Node.js 22+（内置 `node:sqlite`，无需编译原生模块）。
- 扫描版 PDF（图片型）纯文本解析会失败；配置多模态模型后可扩展识别，当前版本会将该文件标记为解析失败并留在 `简历/` 中。
- `简历/` 中的文件处理成功后会被搬走，避免重复处理；同名文件再次放入会自动加 `(1)` 后缀。
